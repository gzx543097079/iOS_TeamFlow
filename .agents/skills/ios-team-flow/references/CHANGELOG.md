# 版本记录

## 1.10.1

## 1.10.0

- 精简仓库入口和需求模板的重复说明，明确先定位再读取、跨会话续接及证据引用方式。

## 1.8.0

- 已验收实施内容绑定确切提交；其他需求修改同目录不再使原验收失效，明确重开后重新验证。
- 测试与验收共用输入规则，排除 Git 元数据及生成物；验收可直接引用真实 result，复用 profile 范围。
- 统一 AC 失败用词；最终门禁统一核对测试，独立 verify 仅用于排错。
- 按事实变化同步；交付记录可随下一次正常提交归档，立即归档仅审记录差异。
- 明确成员/Codex 分工，压缩入口重复说明、新项目启动模板和已有项目动态记录。

## 1.7.0 — 2026-09-11

- 普通 finish 不再覆盖验收基线；完成验收使用 finish --accept 显式绑定范围与证据，代码变化先复核。
- finish 自带写后校验，日常无需追加 --check；新卡 v3 与历史卡分开处理，历史不批量迁移。
- 修复首次门禁的 Python 缓存副作用，以及删除后暂存造成的测试指纹误失效；测试快照算法升级为 v2。
- create 使用 UUID 分配跨分支需求编号，兼容旧数字编号；补充冲突后的尾注和关联修复流程。
- 接入后自动输出只读诊断，并支持 --doctor；不覆盖忽略规则、不自动安装 Hook。
- 新项目分为工程启动、对应功能、发布三个确认阶段；README 同步 1.7.0 版本、安装及日常命令。
