## 1.3.0 — 2026-09-11

## 1.2.2 — 2026-09-11

## 1.2.1 — 2026-09-11

- 规则、模板、版本与门禁实现改为直接维护在 `.agents/skills/ios-team-flow/`，移除旧规范目录和同步脚本。
- 项目接入记录改为 `.agents/teamflow.json`；接入、校验和两种分发包均使用 Skill 内资源。

- 超大字号默认仅在明确要求时测试；PRD 独立列出深色模式和跟随系统配置，默认均为是。

- 同步项目 Skill 资源及工作流执行规则。

## 1.0.0 — 2026-09-11

首次正式发布；此前开发阶段曾使用的 1.1.0、1.2.0 为本地草案编号，在本次首发时尚无对应线上版本，与后续正式发布分别记录。

- 中文 Codex AGENTS.md 与项目级独立 Skill，项目接入一次，团队随 Git 共享规范与版本。
- Apple UI 基线，Objective-C / Swift / SwiftUI 按需规范。
- 需求拆分、过程状态追踪、新项目 PRD 模板与确认流程。
- 本次改动提交前审查与指纹去重，覆盖订阅价格/文案/产品一致性、内存、打点、测试残留。
- 保留现有规则的项目接入脚本，空项目接入说明、冲突与版本预检。
- 独立 Skill ZIP、整套项目分发包、SHA256 校验和 GitHub Release 附件自动化。
- 17 项行为测试，包含脱离源仓库、项目复制和幂等接入验证。
