# 版本记录

## 3.2.0

- 主流程统一为“明确范围 → 实施与随改随测 → 最终验收 → 按明确目标交付”，入口和 README 引用唯一规则源。
- 测试改为自动发现，删除失效的增量选择器及按文案副本维护的断言。
- 待用户验证允许保留未确认 AC；完成状态只能经证据检查进入，需求模板省略重复验证状态与空字段。
- 验证增加 `--requirement`，绑定本次需求和所选 profile 的有效配置；无关需求、其他 profile 与配置排版变化不使证据失效。
- 删除 `release prepare`；准备时直接检查真实环境，保留按 build 的发布事实记录。模块索引与复杂功能文档按需使用。

- 统一验证 CLI，`req complete --profile` 一次执行验证并绑定结构化证据，完成和提交检查自动复用并核对证据。
- 验证配置改为 schema 2，每个 profile 集中定义输入与命令，不保留旧配置兼容。
- 移除重复接入版本清单、导航和缺陷模板；复用项目路径校验与 ZIP 打包实现，同次测试共享 Skill ZIP。
- 清理旧需求、delivery 与 review 台账，历史资料通过 Git 提交定位；保留当前需求与验证闭环。

- commit、push、PR、标签、GitHub Release、Archive、TestFlight、审核、发布和下架均改为独立显式授权。
