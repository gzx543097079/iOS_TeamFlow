## 启动阶段（首次只填写本节）

- 文档版本、产品/技术负责人、关联需求：待填写。
- 用户与问题、首个可演示范围、本期不做：待填写。
- 演示操作与预期结果：引用需求卡 AC，不重复维护结果。
- 产品名、工程/Target 名、显示名、实际 Bundle ID：待确认；用户说 buildid 时先明确含义，不使用示例 ID 冒充实际值。
- 开发环境：实际 Xcode/SDK/Swift 模式、运行设备和当前开发语言。
- 技术建议（均待团队接受或调整）：Swift + UIKit、iOS 14.0、按功能组织的 MVVM、导航栈及导航栏、无 Tab Bar、支持深色且跟随系统；App/ 与 requirements/ 同级。
- 实际最小目录及职责：仅列当前有内容的目录、Target 与资源归属；不生成空壳模块，不预装架构库或无用依赖。
- 启动必需数据/接口/权限及限制：只填写演示范围实际依赖，权限必须明确用途、请求时机和拒绝处理。
- 可延后事项：事项 → 负责人 → 功能实施前或发布前；不重复填写整套后期配置。

将以上具体版本交团队确认，记录确认人、时间（含时区）、范围和原文/链接。没有明确确认不创建工程与业务代码；批准启动不等于批准后续功能。确认后创建最小可运行工程，实际构建验证，并在 .agents/project-checks.json 配置命令和输入；PRD 引用配置，不抄命令和测试结果。
