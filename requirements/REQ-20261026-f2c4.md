# 一键安装生成验证配置并文档化 AI 迁移

## 范围

- 新增 `install`：从 ZIP 一键接入业务项目（无需人工整包解压复制到项目根）。
- 安装 / setup 时若缺失则生成 `.agents/project-checks.json`（及 iOS 设计变量配置与检查脚本骨架），行为类似创建 `requirements/`。
- README 写明 AI 安装命令与旧验证配置迁移步骤，供 Agent 自动执行；升级工具仍不静默改写业务检查脚本。
- 同步 INSTALL/COMMANDS、打包清单、token 预算窄路径场景与回归测试。

## 不包含

- 不自动改写已有自定义 `project-checks.json` 或业务 `check_*.py`。
- 不发布 App；本卡不强制打 GitHub Release（完成验证即可；发版另卡或用户明确要求时再做）。
- 不迁移颜见等消费项目仓库内的配置（由使用方按 README 迁移段执行）。

## 验收条件

- [x] AC-01：在空 Git 项目对安装包执行一键 `install`（或等价引导入口）后，存在核心、入口、`requirements/`，以及按模式生成的 `.agents/project-checks.json`；重复执行不覆盖已有验证配置。
- [x] AC-02：iOS 模式生成的日常 profile 含 covers/拆分形态与 design-tokens 检查入口，并带可改的 Debug/Release 检查脚本骨架；Godot 模式从既有示例生成；`manual` 含 Release/全量测位。
- [x] AC-03：README 含 AI 一键安装命令，以及 doctor/upgrade 提示「验证配置待迁移」时 Agent 须执行的迁移步骤；INSTALL/COMMANDS 与实现一致。
- [x] AC-04：token 预算场景与窄路由对齐（UI 缺陷不含架构双文档；新增小改动窄路径）；源码适用 `workflow` 检查通过。
