把 pbakaus/impeccable（Apache 2.0）中适用于原生 iOS 与 Godot 游戏 UI 的设计方法，提炼为中文规则融入 TeamFlow：新增 iOS「UI 评审与打磨」专题（评审维度与 0–4 评分、P0–P3 分级、打磨的分诊顺序与偏差归类、“打磨保留、重做替换”的范围纪律、模拟器截图与深浅色/大字号核对命令、模拟器与真机证据区分）；把 iOS 平台一致性规则中现有 UI 规范缺少的部分合并进 UI 规范（系统导航与模态、边缘返回、SF Symbols、单一强调色、系统材质、系统转场、常见“网页移植感”反模式）；Godot 增加游戏 UI 评审小节，复用同一分级；工程现状模板增加产品与设计约定栏目，承载 impeccable 中 PRODUCT.md / DESIGN.md 的作用；路由与授权按 TeamFlow 现有规则：评审只读不建卡，修复建卡或续接原卡；补充第三方来源说明。
