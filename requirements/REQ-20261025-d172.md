# 设计变量改为团队强制并分发 check_design_tokens 检查

## 范围

用户要求严格执行：字体、圆角等 UI 设计值集中在独立模块，业务代码只从该模块读取。
- `standards/ui.md` 设计变量条款由【团队默认】改为【团队强制】：字体、圆角、间距、颜色定义在项目的设计变量模块；模块外不写字面量，缺少的值先在模块中按语义新增；0 与系统语义样式除外。
- iOS 安装包分发 `.agents/skills/iOS/scripts/check_design_tokens.py`，读取项目 `.agents/design-tokens.json`：扫描目录、设计变量模块路径（豁免）、启用的内置规则（font、corner-radius、color、spacing）与自定义正则、基线文件。模块外出现字面量即失败；基线中的存量违规放行，新增违规失败；`--update-baseline` 重写基线；未扫描到任何源文件时报错。
- 新增 `references/DESIGN-TOKENS.md` 说明配置与接入 `project-checks.json`。

## 不包含

- 不修改颜见、Slipwise；不自动迁移项目存量代码。
- 基于正则的源码扫描，不做 Swift 语法解析；字符串内的同形文本可能误报，由基线或调整规则处理。
- 不覆盖 Godot。
